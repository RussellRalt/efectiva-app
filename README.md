# Efectiva

Gestor de tareas web instalable (PWA).

- Funciona de forma estática, sin servidor.
- Los datos se guardan localmente en el navegador de cada dispositivo.
- La integración de IA solicita y guarda la clave de OpenRouter únicamente en el almacenamiento local del dispositivo.

## Publicación

Este repositorio se publica mediante GitHub Pages.

> La carpeta local `versiones backup` y el archivo ZIP de exportación no forman parte de este repositorio.
